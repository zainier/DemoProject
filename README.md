# DemoProject

Навчальний проєкт до практичної роботи №57 «Інженерія індустріального виробництва програмних продуктів. Супровід програм».

## Опис
Консольний застосунок на C# (.NET), на якому відпрацьовано процес супроводу програмного продукту в Git: роботу з гілками за моделлю `dev -> release/* -> master`, випуск версій і ведення журналу змін.

## Версії
- **v1.0** — застосунок запитує ім'я користувача та виводить привітання «Вітаю {ім'я}!».
- **v1.1** — додатково запитує вік користувача та виводить ім'я разом із віком.

## Структура гілок
- `dev` — основна гілка розробки (default branch).
- `master` — стабільна гілка; лише перевірені релізи, зміни тільки через Pull Request (branch protection).
- `release/1.1` — підготовча реліз-гілка для версії 1.1.
